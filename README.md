# 노숙인 무료급식 봉사 관리 — 시작 페이지

수원성교회 노숙인 무료급식 봉사 웹앱을 여는 시작 페이지예요.

- 이 페이지는 구글 웹앱(Apps Script)의 화면을 받아서 띄우기만 해요. 출석·명단·확인서 같은 자료는 여기 없고, 로그인한 뒤 구글 시트에서만 오가요.
- 구글 로그인 정보를 보내지 않아서, 브라우저에 구글 계정이 여러 개 로그인돼 있어도 열려요.
- 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 웹앱 주소가 바뀌었을 때

Apps Script에서 **새 배포**를 만들면 웹앱 주소(/exec로 끝나는 주소)가 바뀌어요. 그때는 `index.html`의 이 한 줄만 고치면 돼요.

```js
var API_URL = 'https://script.google.com/macros/s/……/exec';
```

GitHub에서 `index.html` 열기 → 연필 아이콘 → 따옴표 안의 주소를 새 주소로 바꾸기 → **Commit changes**.
([배포 관리]에서 기존 배포를 '새 버전'으로 고치는 경우에는 주소가 그대로라서 고칠 필요가 없어요.)

## 웹앱 배포 설정

Apps Script → 배포 → 배포 관리에서 **실행: 나**, **액세스 권한: 모든 사용자**여야 이 페이지에서 열려요.
